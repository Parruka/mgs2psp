Levers [I]: no I/O test at proven-RAM sites, host pointers for invariant bases, clock in a register across loops: 30 -> ~21 slots a pass, ~1.4x on loop code. Hand-native is CLOSED (910 functions; top 10 = 38%, top 50 = 74%, top 200 = 95%). BATCH 3 DONE 2026-11-28 05:27 (attic/gl45_gen/gl45_gen.md): the three levers are exact on the twin (11 whole-route runs) but SMALL over the top 200: best mix -4.7% slots = ~0.65 ms a rain step [I] (the walker's -20% was the best case); 0.9 ms more sits in I/O tests on pointers that change inside a function (not reachable exactly); cost +70 to 380 kB code and a redone PGO/layout. LEAD DECISION 05:3x: generator levers NOT in gl45 (kept as a later option); the logic's code quality is CLOSED as a lever: the translated logic is near its floor.
